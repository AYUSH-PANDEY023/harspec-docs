Contributing

harspec is open source (MIT). Bug reports, docs fixes and new generators are all welcome.

git clone https://github.com/AYUSH-PANDEY023/harspec.git
cd harspec
python -m unittest discover -s tests -v
I want to...Do this
Report a wrong resultOpen an issue with a redacted snippet, what you expected and what you got.
Add a generatorSee Write a generator.
Improve detectionEdit paths.py or schema.py and add a test.
Fix these docsEdit build.py in the docs repository, run python build.py, open a pull request.

Ground rules

  • Never include real secrets or private captures in tests, issues or examples.
  • Keep the core dependency-free.
  • Add a test for every behaviour change. One change per pull request.
  • Be kind: see the Code of Conduct.

Full details: CONTRIBUTING.md.

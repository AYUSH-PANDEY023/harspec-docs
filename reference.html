Command line

harspec HAR_FILE [options]
OptionDefaultMeaning
-o, --out DIRharspec-outOutput directory (created if missing).
-f, --formats LISTallComma list of generators, e.g. typescript,python.
--host HOSTbusiest hostOnly use requests to this host.
--title TEXThost nameTitle in the OpenAPI info block.
--jsonoffWrite openapi.json instead of openapi.yaml.
--no-clusteroffDo not detect mixed alphanumeric IDs.
--include-staticoffKeep html, js, css and image requests.
--list-generatorsList built-in and plugin generators, then exit.
--versionPrint the version.

Exit codes: 0 success, 1 unreadable or invalid HAR, or no API traffic found, 2 bad arguments.

Operation naming

Operation IDs come from the method and path: GET /users/{user_id}/posts becomes getUserPosts. Collections keep the plural (getPets), items use the singular (getPet). Duplicates get a numeric suffix. Python methods are the snake_case form (get_user_posts).

OpenAPI extensions

FieldMeaning
x-harspec-samplesNumber of captured requests behind the operation. Low numbers mean low confidence.
